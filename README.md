# 实验三：Benchmark 1 + SGLang 交付包

已完成经确认的V100兼容复现：三张同型号、同规格Tesla V100-SXM2-32GB，每组独占一张GPU，S0/S1/S2并行；共21个测点、2184个正式请求，全部成功。

## 从这里开始

1. 打开 [中文实验报告](report/实验报告.html)：自包含HTML，双击即可阅读，不需要联网或启动服务。HTML通过结构验证，自动浏览器验收超时；静态阅读备份为下一项的Markdown与PNG。
2. [报告Markdown源稿](report/实验报告.md) 和 [汇总CSV](results/summary.csv) 可用于修改或引用；五张PNG在 `results/figures/`。
3. 查看 [运行说明](docs/运行说明.md)、[需求对照与指标字典](docs/需求对照与指标字典.md)、[验收与统计检查](docs/验收与统计检查.md)。

本包是实验代码与证据交付，不包含模型权重、虚拟环境或其他项目数据。模型约6.17 GB，仍保留在服务器原路径；本包提供精确SHA256。

## 不用GPU即可验收

在交付包根目录运行（Python3.11+）：

```bash
python3 -B scripts/verify_delivery.py
```

该命令会校验文件、数据集、实测源码、2184次请求、token/传输会计，并从原始数据复算21点指标与交付汇总逐项比较。不会连接服务器、安装包或使用GPU。

## 结果边界

HiCache增加缓存复用，但不同负载的延迟收益不一致，不能表述为全面加速。未量化模型、FP16 KV、SGLang0.4.6.post5/native适配与原量化/BF16设置不同，故本包明确标为“兼容复现”，不宣称严格原配置复现。原始证据已经校验和复算，独立GPU重跑尚未做。

三组共享主机CPU/内存；S0提前启动。精确时间、UUID和完整运行命令留在raw，不影响正文以三张相同规格显卡描述硬件。

## 结果CSV字段

所有结果按baseline × point分别统计；每点100请求，压力点128请求。mean/p50/p95/p99均为描述性样本统计，分位数使用排序后线性插值。

| 指标 | CSV字段 | 定义 / 不可混用项 |
|---|---|---|
| TTFT / E2E | ttft_ms_* / e2e_ms_* | 实际发送HTTP起算，ms |
| 含客户端排队延迟 | offered_ttft_ms_* / offered_e2e_ms_* | 计划到达起算，ms |
| 客户端等待 | client_wait_ms_* | 等待并发槽，不等于纯设备queue time |
| ITL | itl_ms_* | SSE块间隔/新增tokens，块内平均分摊；非独立样本 |
| 请求decode窗口 | decode_window_ms_* | 首块到末块到达跨度，非纯GPU计算 |
| 批次prefill/decode | batch_prefill_cuda_ms_* / batch_decode_cuda_ms_* | CUDA事件跨度，含流内等待与CPU发射间隙 |
| Request / Output吞吐 | request_throughput / output_token_throughput | 完成请求或输出tokens/测量秒数 |
| Logical / Physical总吞吐 | logical_token_throughput / physical_token_throughput | input+output或computed_prompt+output / 秒 |
| Prefill吞吐 | prefill_token_throughput | computed_prompt / prefill批次CUDA跨度和，非裸kernel吞吐 |
| Peak输出吞吐 | peak_output_tokens_per_1s | SSE到达时间的1秒滑动窗口峰值 |
| GPU/CPU KV占用 | gpu_kv_usage_* / host_kv_usage_* | 批次采样，峰值与样本均值，非时间加权均值 |
| 总复用tokens / 比例 | cached_tokens / cache_hit_ratio | meta_info.cached_tokens；S2含GPU和host复用 |
| 逻辑查询分母 | prompt_tokens | 真实输入tokens，非框架每次树查询计数 |
| GPU本地复用 | gpu_reuse_tokens / gpu_reuse_ratio_of_prompt | 总cached减host回载；分母仍为prompt tokens |
| host复用 | host_reuse_tokens / host_reuse_ratio_of_prompt | init_load_back新增前缀tokens；不能叫external hit rate |
| 外部查询分母 | external_query_tokens | null，未独立测量，故不构造external_hit/query |
| GPU驱逐 | evicted_tokens / evicted_tokens_per_s | 分配器可用tokens增量/测量秒数 |
| 实际重算prompt | computed_prompt_tokens | prefill批次实际extend_input_len之和 |
| 双向字节与操作数 | gpu_to_cpu_bytes / cpu_to_gpu_bytes / *_operations | payload字节；方向粒度分别为打包批次/逐层 |
| 双向累计耗时 | *_host_call_s / *_cuda_elapsed_s | 阻塞调用墙钟和CUDA跨度，均非裸DMA |
| 单次大小分布 | *_size_bytes_mean/p50/p95/p99 | bytes；详细CSV另给MiB p50/p95 |
| 有效带宽 | *_GBps_by_host_call_s / *_GBps_by_cuda_elapsed_s | Δbytes/对应Δtime/1e9；无传输为null |
| token会计校验 | cached_compute_accounting_difference | computed - (prompt-cached)，本次全部0 |
| 回载会计校验 | host_transfer_accounting_difference_bytes | H→D bytes - host_tokens×36864，本次全部0 |

未独立记录：精确设备queue time、KV load stall、reuse distance、overlap ratio、external query分母。load amplification不把恒等式回载会计比值冒充真实“有用加载”效率。没有SLO，不计算goodput。Benchmark2/3相关任务指标不适用。

# V100 实验图表口径

输出为课程复现实验的本地 PNG 图、CSV 和 Markdown 说明，不上传到外部服务。
由 `scripts/analyze_v100_experiment.py` 从保存的原始请求和观测事件生成；最终须渲染检查。
图表不预先写入“更快”“改善”等结论，实际结论以完成的数据为准。

| 图 | 问题 | 形式 | 数据粒度与数量 | 主要限制 |
|---|---|---|---|---|
| qps_latency.png | 共享前缀负载随QPS变化的TTFT/ITL如何变化 | 两联离散点折线 | 每组3个QPS，单点100请求，3组 | 只连接3个实测点，不拟合或外推；不是时间趋势 |
| context_latency.png | 固定QPS下输入长度与延迟的关系 | 两联离散点折线 | 每组3种长度，单点100请求，3组 | 横轴用实际平均tokens；不同长度会影响缓存压力 |
| pressure_latency_cdf.png | 压力点的尾延迟分布 | 两联经验CDF | 每组128个TTFT；ITL为同组请求内流式块分摊样本 | 同请求ITL样本相关，不视为独立重复实验 |
| core_cache_throughput.png | 三类核心负载的命中与吞吐对比 | 分组柱状图 | 3负载×3配置 | 吞吐含到达间隔/排队；不能解读为饱和硬件上限 |

固定配色：S0中性灰 `#616161`，S1蓝 `#2774AE`，S2橙 `#D27B2A`。
用圆/方/三角、实线/虚线/点划线及柱填充纹理保证灰度可分。白底、浅灰网格、深灰文字。
线图坐标从0开始；CDF纵轴固定0–1。每图约12×4.8英寸，180dpi，中文字体。

可复核的数据不只包含图形的x/y：CSV还包括目标/实际ISL、QPS、seed、并发、请求数、token分子分母、输入SHA256及原始结果路径。
原始JSON保留请求时间戳、SSE块及分摊方法，传输事件保留方向、字节和两种时间口径。

出图前检查：21点状态、代码/GPU一致性、配对输入、请求完成率、输出长度、数值有限、S0命中为0、测量窗口没有其他请求。
若只有部分点完成，图只能标为阶段性结果；最终完整状态不得仅凭PNG生成成功判断。
出图后检查：标题/标签不重叠、图例可读、单位齐全、灰度可分、没有超出实测证据的标题或注释。
